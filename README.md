# Node.js Practice Programs

This repository contains 14 Node.js lab programs covering core modules, asynchronous programming, file handling, streams, MongoDB, and Express.js.

## Technologies Used

- JavaScript
- Node.js
- npm
- MongoDB
- Express.js

## Programs List

- [ ] **Program 1:** Develop a program using suitable npm packages in Node.js.
- [ ] **Program 2:** Develop a Node.js program to handle events using the EventEmitter class and custom event listeners.
- [ ] **Program 3:** Develop a Node.js program to execute functions asynchronously using timers (`setTimeout`) and callback functions.
- [ ] **Program 4:** Develop a Node.js program to perform asynchronous file operations using the `fs` module.
- [ ] **Program 5:** Develop a Node.js program to implement a simple task queue using callback functions.
- [ ] **Program 6:** Develop a Node.js program to create, access, and manipulate JSON data.
- [ ] **Program 7:** Develop a Node.js program to demonstrate data handling using the Buffer module.
- [ ] **Program 8:** Develop a Node.js program to transfer data using Readable and Writable Streams.
- [ ] **Program 9:** Develop a Node.js program to copy a text file using Streams.
- [ ] **Program 10:** Develop a Node.js program to parse URLs and extract query string parameters.
- [ ] **Program 11:** Perform CRUD operations in MongoDB using shell.
- [ ] **Program 12:** Develop a Node.js program to establish a connection with MongoDB and display a successful connection message.
- [ ] **Program 13:** Develop a Node.js program to perform CRUD operations on a MongoDB collection using the MongoDB driver.
- [ ] **Program 14:** Develop an Express.js application using routing and request-response objects.

## Prerequisites

Install the following tools before running the programs:

- [Node.js](https://nodejs.org/)
- [MongoDB Community Server](https://www.mongodb.com/try/download/community)
- [MongoDB Shell](https://www.mongodb.com/try/download/shell)
- [Visual Studio Code](https://code.visualstudio.com/)

## How to Run

Clone the repository:

```bash
git clone https://github.com/saideep2006/nodejs-practice-programs.git
```

Navigate to the project directory:

```bash
cd nodejs-practice-programs
```

Install the required npm packages:

```bash
npm install
```

Run a Node.js program:

```bash
node filename.js
```

Replace `filename.js` with the name of the program you want to execute.

## Learning Objectives

- Understand Node.js fundamentals and npm packages.
- Learn event handling and asynchronous programming.
- Perform file operations using the `fs` module.
- Implement callbacks and task queues.
- Work with JSON, buffers, streams, and URLs.
- Perform CRUD operations using MongoDB.
- Build web applications using Express.js.
